# AI implementation reminders

Before changing a dashboard card, check for redundancy.

1. Status belongs only in the status badge.
2. Owner belongs only in the top-right owner field.
3. Scope belongs only in the scope chips.
4. The three metric slots must each answer a different decision question.
5. Do not apply highlighted/featured card styling by default. Highlighting is hover or keyboard-focus feedback only.

If a new card field repeats one of those facts, replace it with a distinct, formula-backed proposal summary or remove it.
